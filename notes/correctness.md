# Answer correctness per configuration

Generated by `scripts/score_correctness.py` from the finished run directories; do not edit by hand. The brief asks for retrieval hit rate **and** answer correctness (brief item 5, `notes/report-factcheck.md` §2 row 17); hit rate has lived in `reports/matrix.*` since ticket 15, and this is the correctness half.

**What this measures.** For every *answerable* item of the Golden QA Set (`golden/v1.jsonl`, 40 of the 60), one hosted judge call (`deepseek-v4-pro`) is asked whether the generated answer agrees with the item's `reference_answer`. This is answer correctness against a reference, not faithfulness: faithfulness is whether the cited chunks support the claims, which `ragqa/evaluate.py` reports and which can be high while the answer is wrong. `GLOSSARY.md` files "correctness" under *Avoid* for **Faithfulness** to keep the two apart; the word is used here because that is the brief's word for this measurement.

**Three numbers, never one.**

| column | question it answers |
|---|---|
| `accuracy_all` | of all 40 answerable items, how many did the system get right? An abstention counts as not correct. |
| `accuracy_answered` | of the items the system chose to answer, how many are right? Abstentions leave the denominator. |
| `abstentions` | how much work the first number's denominator is doing. |

Both accuracies share a numerator (an abstention is never correct) and differ only in the denominator, which is why folding them into one number would hide exactly the trade-off the abstention threshold moves. Intervals are percentile bootstraps over items: 10000 resamples, seed 20261030 (per cell, derived from the cell name so one cell's interval does not move when another finishes), 95% confidence.

Abstentions are not sent to the judge: the generator already decided the answer, so a call could not change the verdict. That caps spend at one call per answerable item.

## Regenerate

```
python scripts/score_correctness.py --runs-root <runs root> --report-json reports/correctness.json --report-csv reports/correctness.csv --note notes/correctness.md
```

Run from the checkout that owns the run directories, with `LLM_BASE_URL` and `LLM_API_KEY` in `.env`. The first pass costs one call per answered item; every later pass is free and byte-identical because `LLMClient` caches by content hash.
